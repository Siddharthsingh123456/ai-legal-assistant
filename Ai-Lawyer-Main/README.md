# AI Legal Assistant — Application Folder

This directory contains the React/Vite frontend for the AI Legal Assistant project.

For the full project overview, setup instructions, deployment guidance, and responsible-use notice, see the [repository README](../README.md).

## Local development

From this directory:

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run preview
npm run lint
```

The project uses React 19, Vite 6, React Router, Tailwind CSS 4, and the icon libraries listed in this directory's `package.json`.

Do not place private API keys in frontend source code. Any legal information generated by the application must be independently verified against authoritative sources and is not a substitute for advice from a qualified lawyer.
